Mall Customer Segmentation using KMeans Clustering

This project demonstrates customer segmentation using the KMeans clustering algorithm on the Mall Customers dataset. The objective is to group customers into distinct clusters based on their age, annual income, and spending score, helping businesses understand customer behavior and personalize marketing strategies.


🚀 Getting Started

1. Clone the Repository

git clone https://github.com/yourusername/Mall-Customer-Segmentation.git
cd Mall-Customer-Segmentation

2. Install Dependencies

pip install -r requirements.txt

3. Run the Notebook

Use Jupyter Notebook or any Python IDE to open and run the notebook:

jupyter notebook notebooks/mall_customer_segmentation.ipynb

🧪 Features Used

Age

Annual Income (k$)

Spending Score (1-100)

📊 Techniques Applied

Exploratory Data Analysis (EDA)

KMeans Clustering

Elbow Method (to determine optimal number of clusters)

2D and 3D Visualizations

📎 Output

Segmented customers into 5 distinct clusters

Visual understanding of customer types

Grouped CustomerIDs for each segment
